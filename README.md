App Description: A Pokémon finder application that allows users to search for Pokémon by name or ID, view detailed stats and information, and save their favorite Pokémon with personal notes to a MongoDB database.

APIs: [PokéAPI](https://pokeapi.co/)

## Features

- 🔍 Search Pokémon by name or Pokédex number
- 📊 View detailed stats, abilities, height, and weight
- ❤️ Save favorite Pokémon with personal notes
- 💾 Data persists in MongoDB database
- 🎨 Clean, modern UI with responsive design

## Tech Stack

### Frontend
- React with TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React Icons

### Backend
- Node.js
- Express.js
- MongoDB with Mongoose
- CORS enabled for API requests

## Usage

1. **Search for Pokémon**: Enter a Pokémon name or ID in the search bar
2. **View Details**: Click on a Pokémon to see stats, abilities, and more
3. **Add to Favorites**: Write a personal note and click "Add to Favorites"
4. **View Favorites**: Navigate to the Favorites page to see all saved Pokémon
5. **Update Notes**: Edit notes for existing favorites
6. **Remove Favorites**: Delete Pokémon from your favorites list
